About mytasks

Your data is stored locally in this browser (localStorage). It persists between sessions on this device but isn't synced anywhere.
Link file (Chrome/Edge) auto-saves every change to a real .json file on your disk, so your data survives even if browser storage is cleared.
Export downloads a one-off backup. Import loads a backup back in, merging or replacing your current library.
Nothing here ever leaves your machine — there's no server, no account, and no admin rights required to run this app.
